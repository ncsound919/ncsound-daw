## Manual smoke (required — nothing automated covers this code)

Launch `NCSoundHub` on the demo session and confirm, in order:

1. Arrange shows the 16 tracks, clips, ruler and playhead exactly as before.
2. Click a clip → selection outline; drag it → it moves and the inspector follows.
3. `Ctrl+Z` / `Ctrl+Shift+Z` → the drag undoes and redoes.
4. Toolbar tool switch (select / draw / split) → cursor and behaviour change.
5. Wheel over the ruler → zoom; wheel over lanes → horizontal scroll.
6. Right-click a clip → menu opens; split, duplicate, delete each work.
7. Drag a fade handle and a clip gain handle → both move.

Any visual difference from the pre-refactor build is a failure, not an improvement.

## Risks

- **`NCSoundHub` is the only target that compiles these files.** A source added to
  `NCMixRackTests` by copy-paste will fail to link (it would pull in the whole GUI). Add to
  `NCSoundHub` only.
- **Detached lambdas capture `this` through `SafePointer` in several places.** A move must not
  hoist them out of their function scope.
